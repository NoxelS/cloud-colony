# cloud-colony

A foundation for self-hosted cloud agents.

## Installation

Use the Node.js version in [`.node-version`](.node-version) and the pnpm version in [`package.json`](package.json).

```sh
pnpm install --frozen-lockfile
cp -n .env.example .env
chmod 600 .env
pnpm dev
```
